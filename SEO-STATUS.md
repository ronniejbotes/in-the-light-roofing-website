## Before changing anything on this site

1. Read `LOG.md` (newest entry) and `PLAN.md`.
2. Check `number-register.md` before touching **any** figure. A number may already
   be verified and locked, or already retired.
3. If the change matches an existing task, do **that** task and tick it. Do not
   invent a parallel one, and do not start a competing audit.
4. Write a `LOG.md` entry afterwards. An undocumented change desyncs the programme
   and the next scheduled run will fight it.

Anything containing a number, a price, a credential, a named client, a testimonial
or a competitor claim is **needs-ok**: a person approves it before it ships.
